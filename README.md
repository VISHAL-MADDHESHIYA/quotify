# Quotify — Random Quote Generator

A modern, responsive Random Quote Generator with a premium dark/neon/glassmorphism UI. Built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- 🎲 **Random Quote Generation** – Get a new inspirational quote with a single click.
- 📋 **Copy to Clipboard** – Easily copy the current quote and author.
- 📤 **Share** – Share quotes via native Web Share API (mobile) or copy to clipboard (desktop fallback).
- 📊 **Statistics** – Shows total quotes, instant generation, and tech stack.
- 🎨 **Premium UI** – Dark theme with neon glows, glassmorphism, and smooth animations.
- 📱 **Fully Responsive** – Works beautifully on desktop, tablet, and mobile.
- ⌨️ **Keyboard Shortcut** – Press `Space` to generate a new quote.
- ♿ **Accessible** – Focus outlines, ARIA labels, reduced motion support.

## 🛠️ Tech Stack

- **HTML5** – Semantic markup.
- **CSS3** – Custom properties, flexbox, grid, animations, glassmorphism, media queries.
- **JavaScript (Vanilla)** – No frameworks or libraries.
- **Google Fonts** – DM Sans & Space Grotesk.
- **Font Awesome** – Icons.
